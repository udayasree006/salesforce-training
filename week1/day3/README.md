# Salesforce Summer Program - Day 3

## 1. Difference Between App, Object, Record and Field

### App
Collection of related tools and objects.

### Object
Stores data like a table.

### Record
One row of data inside object.

### Field
A column that stores information.

---

## 2. Standard vs Custom Objects

### Standard Objects
Already provided by Salesforce.
Examples:
- Account
- Contact

### Custom Objects
Created by users.
Examples:
- Student
- Faculty

---

## 3. College Management System

### Objects
- Student
- Faculty
- Course
- Department

### Relationships
- One Department has many Students
- One Department has many Faculty
- One Faculty teaches many Courses

---

## 4. Formula Fields

### Full Name
Automatically combines first and last name.

### Remaining Seats
Calculates available seats automatically.

### Percentage
Calculates student percentage automatically.

---

## 5. Validation Rules

### Age cannot be negative
Prevents invalid age data.

### Email cannot be empty
Ensures communication details exist.

### Filled seats cannot exceed total seats
Prevents overbooking.

---

## 6. Reflection

Structured data helps companies:
- Organize information properly
- Reduce errors
- Build relationships between data
- Generate reports easily
