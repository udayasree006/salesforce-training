# Week 1 - Day 2

## What is Salesforce Platform?

Salesforce Platform is a cloud-based platform that helps companies build and manage business applications, customer data, and workflows in one place. It provides tools for sales, service, automation, and development.

---

## What is an App in Salesforce?

An App in Salesforce is a collection of tools, tabs, and features grouped together for a specific purpose. Apps help users access related data and functions easily.

### Example
Sales App helps sales teams manage customers and opportunities.

---

## What is an Object?

An Object in Salesforce is used to store data. It is similar to a table in a database.

### Example
Account, Contact, and Opportunity are standard Salesforce objects.

---

## What is a Tab?

A Tab is used to open and access objects, records, or pages in Salesforce.

### Example
The Account tab opens all account-related records.

---

## Difference Between Configuration and Coding

Configuration means customizing Salesforce using clicks without writing code. Coding means using programming languages like Apex for advanced functionality.

### Configuration Examples
1. Creating fields using setup
2. Creating workflows and validation rules

### Coding Examples
1. Writing Apex triggers
2. Building custom integrations using APIs

---

## Connecting Day 1 and Day 2 Concepts

CRM concepts like Account, Contact, and Opportunity are stored as Objects inside Salesforce. These objects are grouped inside Apps so users can easily manage customer and business data.

---

## Difference Between App and Object

An App is a collection of features, tabs, and objects used for a specific business purpose. An Object is used to store specific types of data inside Salesforce.

---

## What is Multi-Tenant Architecture?

Multi-tenant architecture means multiple companies use the same Salesforce platform and infrastructure securely while keeping their data separate and protected.

---

## How Salesforce Allows Developers to Extend Functionality

Salesforce allows developers to extend functionality using Apex, Lightning Components, APIs, automation tools, and custom applications.

---
