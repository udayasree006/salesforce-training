# Salesforce Summer Program - Day 4

## What is Flow Builder?
Flow Builder is a Salesforce automation tool used to automate business processes without coding.

## Types of Flows

### Screen Flow
Used for user interaction and forms.

### Record Triggered Flow
Runs automatically when records are created or updated.

## Automation Ideas
1. Auto email after registration
2. Auto generate student ID
3. Auto fee reminder
4. Notify faculty when course full
5. Auto update remaining seats
