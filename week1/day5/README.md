# Day 5 - Salesforce Apex Basics & Database

Today I practiced Apex programming fundamentals in Salesforce Trailhead.

Topics covered:
- Apex Classes and Methods
- Lists and Collections
- sObjects
- DML Operations
- SOQL Queries
- SOSL Queries
- Working with Contacts, Leads, and Accounts
- Debugging Errors in Salesforce Flow

Tasks completed:
- Created Apex classes using public static methods
- Inserted and updated records using DML
- Wrote SOQL queries to retrieve contact records
- Wrote SOSL queries to search Contacts and Leads
- Learned how to use Execute Anonymous Window
- Debugged Flow related errors while creating Lead records

Challenges completed:
- StringListTest
- AccountHandler
- ContactSearch
- ContactAndLeadSearch

Key learning:
I understood the difference between SOQL and SOSL and learned how Salesforce automation can affect Apex operations.
